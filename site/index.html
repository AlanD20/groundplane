Install Groundplane __VERSION__

Ubuntu 24.04 or 26.04, or Debian 13. Linux amd64 and arm64.

curl -fsSLO https://gp.aland20.com/install.sh
curl -fsSLO https://gp.aland20.com/install.sh.sha256
sha256sum --check install.sh.sha256
# Inspect install.sh before running it.
sudo sh install.sh --version __VERSION__

The installer verifies the downloaded bundle checksum and its file manifest before running bundled code. Checksums detect altered bytes; they are not an independent publisher signature.
