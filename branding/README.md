# Groundplane branding

The Anchor mark places a stable square between two opposing, open corners.
The center represents the control plane; the open boundaries leave room for
independent workloads. Preserve all three shapes and their spacing.

Use the supplied geometry unchanged: no rotation, connecting strokes or enclosing
frame. The open diagonal and separated center are part of the mark, including at
favicon sizes. This replaces the earlier geometric G, which resembled Gitpod.

- `mark.svg`: primary purple mark on transparent background.
- `mark-monochrome.svg`: one-color mark; source for the shared Console/Site BrandMark.
- `favicon.svg`: white mark on purple tile, optimized for browser tabs.
- `wordmark-light.svg` / `wordmark-dark.svg`: complete lockups for the named background.
  IBM Plex Sans is embedded so they render without an installed font.
- `FONT-LICENSE.txt`: license for the embedded IBM Plex Sans font.

Minimum mark size: 16 px; use 24–32 px in navigation. Leave at least one-quarter
of the mark width clear around it. Never stretch, add shadows, or replace it with
a generic Layers icon. The platform component uses the primary theme token and
this same monochrome asset. Both builds import the favicon from this folder.

The design is not trademark-cleared. A focused visual screen is not a comprehensive
search of marks, unregistered use or the Groundplane name in intended markets.
